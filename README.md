# Concurso Agrinho 2026 - Front-End 🌾

## 📋 Sobre o Projeto
Este site foi desenvolvido para o Concurso Agrinho 2026 com o tema: *"Agro forte, futuro sustentável: equilíbrio entre produção e meio ambiente"*. 

O objetivo do projeto é conscientizar as pessoas sobre a importância de produzir alimentos utilizando a tecnologia para proteger a água, o solo e as florestas, garantindo o sustento de hoje sem estragar o amanhã.

## 🚀 Tecnologias Utilizadas
* **HTML5 Semântico:** Para criar a estrutura organizada e os textos do site.
* **CSS3 Externo:** Para aplicar as cores (tons de verde) e deixar o visual bonito e limpo.
* **JavaScript Vanilla Externo:** Para criar a interatividade do botão que mostra informações extra ao utilizador.
