# Concurso Agrinho 2026 - Front-End 🌾

## 📋 Sobre o Projeto
Este site foi desenvolvido para o Concurso Agrinho 2026 com o tema: *"Agro forte, futuro sustentável: equilíbrio entre produção e meio ambiente"*. 

O objetivo da página é mostrar os pilares essenciais para produzir alimentos protegendo a natureza. O site conta com uma seção explicativa, uma lista com as principais práticas sustentáveis no campo (como rotação de culturas e uso consciente da água) e um botão interativo com dicas de manejo.

## 🚀 Tecnologias Utilizadas
* **HTML5 Semântico:** Para a estrutura dos textos, cabeçalho, seções e listas.
* **CSS3 Externo:** Para estilização visual com cores que remetem à sustentabilidade (tons de verde e laranja).
* **JavaScript Vanilla Externo:** Para controlar a interatividade do botão de dicas (mostrar/esconder a mensagem).
